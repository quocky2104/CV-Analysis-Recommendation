## KEY RESPONSIBILITIES

- **Architecture & System Design:** Collaborate with architects and product teams to design, develop, and maintain robust, high-throughput backend services using **Python** (FastAPI / Django) and clean **RESTful API** architectures.
- **Frontend Development:** Engineer performant, accessible, and intuitive web interfaces utilizing **React.js** and **Next.js**, ensuring sub-second page loads and seamless user experiences.
- **Database Engineering & Optimization:** Design schemas and optimize queries in relational database systems (**PostgreSQL** / MySQL), utilizing indexing strategies, query plan analysis, and caching patterns for mission-critical datasets.
- **Containerization & CI/CD:** Package microservices and web applications using **Docker**, build and maintain automated CI/CD pipelines, and collaborate with DevOps engineers to deploy to cloud environments.
- **Code Quality & Peer Review:** Lead thorough code reviews, champion Clean Architecture principles, ensure solid test coverage (unit, integration, and E2E), and maintain security best practices (OWASP).
- **Mentorship & Technical Leadership:** Mentor junior and mid-level software engineers, share technical knowledge via internal tech talks, and foster an engineering culture of continuous learning.

## CANDIDATE REQUIREMENTS

### Must-Have Requirements:
- **3+ years** of professional software development experience in fullstack or backend engineering roles building production-grade web applications.
- Strong proficiency in **Python (3.8+)** and modern Python web frameworks, preferably **FastAPI**, **Django**, or Flask.
- Strong proficiency in modern frontend development with **React.js** or **Next.js**, with a solid grasp of component lifecycles, state management libraries (Redux Toolkit, Zustand, or Context API), and modern hooks.
- Proven expertise in designing, securing, and documenting standard **RESTful APIs** (OAuth2, JWT authentication, rate limiting).
- Solid foundation in relational database management systems (**SQL databases**, specifically **PostgreSQL** or MySQL), including schema normalization, index optimization, and transaction safety.
- Proficient in version control systems using **Git** (Gitflow branching models, pull request workflows, merge conflict resolution).
- Strong problem-solving mindset, analytical thinking, and effective communication skills.

### Preferred Qualifications:
- Solid experience writing type-safe code using **TypeScript** on both frontend and backend.
- Hands-on experience with **Docker** and Docker Compose for development and containerized deployments.
- Practical experience setting up or maintaining automated **CI/CD** workflows (GitHub Actions, GitLab CI, or Jenkins).
- Experience deploying, configuring, or monitoring services on cloud providers (**AWS** services such as EC2, S3, RDS, ECS or **GCP**).
- Practical experience working within an **Agile/Scrum** software development cycle.

### Nice-to-Have Skills:
- Experience designing or consuming **GraphQL** APIs.
- Familiarity with distributed systems and **Microservices architecture**, including message brokers (Apache Kafka, RabbitMQ, or Redis Pub/Sub).
- Prior experience in **mentoring** junior engineers or leading small feature pods (2–4 developers).
- Good written and conversational English communication skills for cross-border collaboration.
- Contributions to open-source software or active participation in technical communities.
